# Contributing

Contributions must be compatible with the MIT license and must include only
material you have the right to contribute. For local review, use Python 3.10+ and run `python -m unittest discover -s tests -v`.
Add tests with synthetic data only. No package installation is required.

Keep creative decisions configurable. Distinguish implemented functions from
proposed adapter interfaces, integrity from quality, and independent observations
from author assertions. Add regression tests for schema bypasses, missing gates,
stale evidence, mode violations, paths and clear error handling. Never copy real
projects, private routing, source catalogs or third-party standards into examples.
Publishing a fork does not authorize account operations or application
submissions on behalf of another owner. Never include private review inputs.
